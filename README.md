# Responsive Gym Website 🏋️‍♂️

This is a **fully responsive Gym Website** built using **HTML & CSS** only.

The site features a clean and modern UI that adjusts smoothly between mobile and desktop devices. It’s a great practice project demonstrating frontend web design skills.
